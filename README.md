# Ammolite

A CSS-in-JS library.

- ✅ Type-safe by default
- 🚫 No runtime overhead by default
- 📦 Optimized for scale

Ammolite provides a scalable way to build layouts using JavaScript/TypeScript without sacrificing performance or adding unnecessary runtime overhead. For developers who already know CSS, it is possible to start using Ammolite immediately.
